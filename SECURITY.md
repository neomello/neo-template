# Security

Report vulnerabilities privately.

- Do not open public issues for active vulnerabilities.
- Use your preferred private contact channel for the target project.
- Include impact, reproduction steps, and any suggested fix.

## Baseline expectations

- No secrets in the repository
- No credentials in examples
- Dependencies kept reasonably current
- Security fixes prioritized over cosmetic work

This file is intentionally short. A real project can expand it if the threat model deserves more
detail.
